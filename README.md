# MaathaCare – Smart Digital Pregnancy Support System
___

# Project Overview

MaathaCare is a smart digital pregnancy support system designed to enhance Sri Lanka’s public maternal healthcare services through technology.

Maternal healthcare services in Sri Lanka are supported by a strong public health system; however, many processes remain manual and paper-based, leading to missed clinic appointments, poor supplement adherence, and challenges in tracking high-risk pregnancies. MaathaCare is a smart digital pregnancy support system designed to enhance Sri Lanka’s public maternal healthcare services through technology. The system consists of a mobile application for pregnant mothers and Public Health Midwives and a web-based dashboard for MOH officers. Key features include appointment and supplement reminders, pregnancy timeline guidance, digital storage of medical records, and emergency contact access for mothers. Healthcare officers can manage mother profiles, monitor clinic attendance, view area-wise statistics, and identify potential risk cases through rule-based alerts. By centralizing pregnancy data and improving communication between mothers and healthcare providers, MaathaCare aims to improve maternal engagement, early risk identification, and overall efficiency of maternal healthcare delivery without replacing established public health practices.

## Technology Stack

- **Mobile Application:** React Native  
- **Backend:** Spring Boot  
- **Database:** PostgreSQL  
- **Authentication:** JWT-based authentication  
- **Notifications:** Firebase Cloud Messaging (FCM)
